## 从注册到能登录：完整购买流程

整个流程大约30分钟，最花时间的其实是实名认证。按顺序走：

1. **注册并实名认证**。个人上传身份证或刷脸，企业上传营业执照和法人信息，审核一般1-2个工作日。这一步没完成，后面买不了。
2. **选付费类型**。业务稳定选包年包月，活动机型年付明显更划算；临时测试选按量付费，按小时结算；抢占式实例单价最低但可能被系统回收，长期业务别碰。
3. **选地域**。用户在国内就近选华北2（北京）、华东1（杭州）或华南1（深圳），阿里云全球有29个地域、90个可用区，还有香港、新加坡、美国等海外节点。要和RDS数据库内网互通的话，必须同地域。注意：地域创建之后改不了。
4. **选实例规格**。新手从2核2G起步，不够再升，别一上来就买高配。
5. **选镜像**。Linux推荐Ubuntu 20.04，适合建站和后端开发；要跑.NET或SQL Server选Windows Server；想省事选云市场镜像，LNMP、Docker都是预装好的。
6. **存储**。系统盘默认40G ESSD Entry，装系统和基础软件够用；数据盘没有明确需求可以先不加，以后再挂载。
7. **带宽和公网IP**。务必勾选“分配公网IPv4地址”，否则公网访问不了。流量波动大选按使用流量计费（0.8元/GB），流量稳定选固定带宽（1M是23元/月）。
8. **安全组**。这是阿里云的“防火墙”，新手放行22（SSH）、80（HTTP）、443（HTTPS）三个端口就够了，其他默认不开更安全。实例创建后建议把规则收紧到仅允许自己的IP访问。
9. **登录设置**。选“自定义密码”。Linux实例登录名推荐用ecs-user（比直接用root安全，需要权限时用sudo提权），部分镜像默认用户仍是root；Windows实例默认登录名是administrator。密码忘了都能在控制台重置。

付款后进ECS控制台，实例状态变成“运行中”就能连：Linux用Xshell、PuTTY输入公网IP和密码，Windows直接开远程桌面连接。
